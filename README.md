# RAG με LangChain (και Ollama)

Το πρόγραμμα απαντά σε ερωτήσεις με βάση το κείμενο από ένα ή περισσότερα PDF. Χρησιμοποιεί τοπικά μοντέλα μέσω Ollama: το `embeddinggemma` για αναζήτηση σχετικών αποσπασμάτων και το `gemma3:12b` για τη σύνθεση της απάντησης.

## Πώς λειτουργεί

1. Το `ingest.py` διαβάζει τις σελίδες των PDF και τις χωρίζει σε μικρότερα αποσπάσματα.
2. Το `index.py` μετατρέπει τα αποσπάσματα σε embeddings και τα αποθηκεύει στη μνήμη.
3. Το `retrieval.py` βρίσκει τα πιο σχετικά αποσπάσματα για κάθε ερώτηση.
4. Το `generation.py` στέλνει την ερώτηση και τα αποσπάσματα στο μοντέλο, ζητώντας απάντηση με παραπομπές `[1]`, `[2]` κ.λπ.

Το `rag.py` συνδέει τα στάδια και παρέχει τη διαδραστική γραμμή εντολών. Στο `config.py` ορίζονται τα μοντέλα, το μέγεθος και η επικάλυψη των αποσπασμάτων, καθώς και το πλήθος των αποτελεσμάτων (`TOP_K`). Το `conflicts.py` περιέχει οδηγίες ώστε το μοντέλο να αναφέρει αντικρουόμενες πληροφορίες· **δεν υλοποιεί αυτόνομη ανίχνευση ή επίλυση συγκρούσεων**.

## Εκτέλεση

Χρειάζονται ενεργό Ollama με τα δύο παραπάνω μοντέλα και οι βιβλιοθήκες Python που χρησιμοποιεί ο κώδικας (`langchain-core`, `langchain-text-splitters`, `langchain-ollama`, `pypdf`). Από το υπάρχον εικονικό περιβάλλον:

```bash
cd ~/ptixiaki/code/pipeline
source ../.venv/bin/activate
python rag.py /διαδρομή/προς/αρχείο.pdf
```

Μπορείς να δώσεις περισσότερα PDF στην ίδια εντολή. Στη συνέχεια γράφεις ερωτήσεις και πληκτρολογείς `exit` για έξοδο. Το ευρετήριο φτιάχνεται ξανά σε κάθε εκτέλεση και οι σελίδες PDF χωρίς εξαγώγιμο κείμενο παραλείπονται.
